# docs

Documents produced or used while developing features in this repository, kept as examples of
agentic development:

- **Specifications** that an agent implements against, such as `content-promotion-widget-spec.md`.
- **Example deliverables** a developer can hand to stakeholders, such as
  `example-call-to-action-decision-flow.md`.
- **Follow-up tasks** in `tasks/`.

Instructions for working in a particular folder live next to that folder's code instead. For
example, the end-to-end test guide is `tests/README.md`.
